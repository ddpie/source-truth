# auto-instrumentation only sees the transport layer (a subprocess call), while this emits GenAI

# possible at all. No agent code calls it: the wheel declares an [opentelemetry_instrumentor] entry
# point, so the opentelemetry-instrument wrapper in the CMD discovers and enables it.
